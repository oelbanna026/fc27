# FC 27 — Defense Lab (نسخة الويب + أوفلاين)

أداة تحضير دفاعي لـ **FC 27**، بقت موقع واحد يفتح من أي متصفح، وبتفضل شغالة بعد كده
**بدون إنترنت**.

| | |
|---|---|
| رابط اللعب | `https://oelbanna026.github.io/fc27-defense-lab/` |
| نوع الموقع | صفحة واحدة (index.html) — مفيش سيرفر ولا قاعدة بيانات |
| الأوفلاين | Service Worker + cache — أول فتحة بالنت وبس |
| التثبيت | PWA — يتثبت كتطبيق على الموبايل والكمبيوتر |

---

## طريقة الاستخدام

1. افتح الرابط **مرة واحدة** والنت شغال.
2. استنى لحد ما تظهر علامة **«أوفلاين جاهز»** في الهيدر (ثانية أو اتنين).
3. بعد كده: اقفل النت أو سافر أو النت يقطع — افتح نفس الرابط واشتغل عادي.

يظهر فوق كمان زرار **«تثبيت على الجهاز»** (في Chrome / Edge) — لو دُست عليه
الموقع يتثبت كأيقونة تطبيق، ويفتح في شاشة كاملة بدون شريط المتصفح.

من الموبايل:

- **Android / Chrome:** منيو ⋮ → *Install app* (أو *إضافة إلى الشاشة الرئيسية*).
- **iPhone / Safari:** زرار المشاركة → *Add to Home Screen*.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | اللعبة نفسها (صفحة واحدة، كل الـ CSS والـ JS جوّاها) |
| `sw.js` | الـ Service Worker — بيحفظ الموقع ويشغّله أوفلاين |
| `manifest.webmanifest` | بيانات التطبيق (الاسم، الأيقونات، شاشة كاملة) |
| `icons/` | أيقونات 192 / 512 / maskable / apple-touch / favicon |
| `404.html` | أي رابط غلط يرجّعك للعبة |
| `play-local.bat` | تشغيل نسخة محلية على `http://localhost:8765/` |
| `tools/make_icons.py` | إعادة توليد الأيقونات |

`.nojekyll` موجود عشان GitHub Pages يستخدم الملفات زي ما هي بدون Jekyll.

---

## التشغيل محلياً (بدون نت خالص)

```bat
play-local.bat
```

أو:

```bat
python -m http.server 8765
```

بعدها افتح `http://localhost:8765/`. مهم تستخدم سيرفر مش `file://`،
لأن الـ Service Worker مش بيشتغل على `file://` في بعض المتصفحات
(الصفحة نفسها بتشتغل بالطريقة الاتنين).

---

## إزاي تحدّث المحتوى

1. عدّل `index.html`.
2. غيّر رقم النسخة في أول `sw.js`:
   ```js
   const VERSION = "fc27-lab-v2";   // أي رقم جديد
   ```
   من غير ما تغيّره، المتصفح هيفضل يعرض النسخة القديمة المحفوظة.
3. ارفع التعديل (push). GitHub Pages بينشر في حدود دقيقة.

## ملاحظة مهمة

دي **أداة تحضير وتدريب** حوالين ميكانيكا الدفاع في FC 27 (اللوحة، التمرين، سجل الأهداف،
المرجع) — مش نسخة من لعبة EA Sports FC 27 نفسها. لعبة EA لعبة Windows ضخمة
بمحرك وترخيص خاص، ومفيش طريقة إنها تشتغل جوه متصفح.

اللي بقى متاح من رابط وبيشتغل أوفلاين هو الأداة دي كاملة، زي ما هي.
